## Color Palette

| Name         | Hex       | RGB              | Usage                                     |
|--------------|-----------|------------------|-------------------------------------------|
| Primary Blue | `#0E52A8` | `14, 82, 168`    | CTAs, links, accents, branded elements    |
| Dark Navy    | `#0B192C` | `11, 25, 44`     | Card backgrounds, secondary surfaces      |
| Background   | `#050816` | `5, 8, 22`       | Page background                           |
| Pure White   | `#FFFFFF` | `255, 255, 255`  | Body text, icons on dark backgrounds      |
| Silver       | `#C0C0C0` | `192, 192, 192`  | Subtle text, secondary information        |

### Color Usage Rules

- **Never** place Primary Blue text on white or light backgrounds without sufficient contrast
- Always ensure minimum 4.5:1 contrast ratio for text (WCAG AA)
- Use the brand background (`#050816`) as the default dark surface
- Tints and transparencies of Primary Blue are permitted for surfaces and glows

## Logo Usage

### Variants Available

| Variant                  | Background Use         | File                              |
|--------------------------|------------------------|-----------------------------------|
| Horizontal — Blue        | Dark backgrounds       | `logo-horizontal-blue.png`        |
| Horizontal — Light       | Dark backgrounds       | `logo-horizontal-light.png`       |
| Horizontal — Dark        | Light backgrounds      | `logo-horizontal-dark.png`        |
| Vertical — Blue          | Dark backgrounds       | `logo-vertical-blue.png`          |
| Vertical — Light         | Dark backgrounds       | `logo-vertical-light.png`         |
| Vertical — Dark          | Light backgrounds      | `logo-vertical-dark.png`          |
| Wordmark — Blue          | Dark backgrounds       | `wordmark-horizontal-blue.png`    |
| Wordmark — Black         | Light backgrounds      | `wordmark-horizontal-black.png`   |
| Wordmark — Light         | Dark backgrounds       | `wordmark-horizontal-light.png`   |
| Icon — Blue              | Any                    | `icon-blue.png`                   |
| Icon — White             | Dark backgrounds       | `icon-white.png`                  |
| Icon — Black             | Light backgrounds      | `icon-black.png`                  |

### Do's ✅

- Use the correct variant for the background color
- Maintain clear space of at least 1× icon height around the logo
- Use SVG favicon for browser tabs and system icons
- Use the horizontal variant for wide spaces (headers, footers)
- Use the vertical or icon-only variant for square/compact spaces

### Don'ts ❌

- Never stretch or distort the logo
- Never change logo colors outside the provided variants
- Never place the logo on a busy or low-contrast background
- Never recreate the logo in a different typeface
- Never use drop shadows on the logo
- Never use the logo at less than 24px height in digital contexts

### Minimum Size

| Context         | Minimum Width |
|-----------------|---------------|
| Digital (web)   | 80px          |
| Favicon         | 16px (SVG)    |
| Print           | 25mm          |

## Voice & Tone

### Attributes

- **Professional** — speaks with authority and expertise
- **Friendly** — approachable and human, never cold
- **Confident** — clear positions, no hedging without reason
- **Practical** — focuses on tangible outcomes, not buzzwords
- **Never arrogant** — success is shared; humility is a strength

### Writing Style

- Use first person ("I build..." not "He builds...")
- Write for a reader, not an algorithm
- Short sentences with clear subject-verb-object structure
- Lead with what matters most
- Avoid jargon unless the audience clearly understands it
- Use active voice over passive
